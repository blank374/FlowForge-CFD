# 通用诊断网格的质量适配

适配过程不读取模型文件名或特定模型哈希来选择参数。初始体网格按界面参数生成，默认开启自动质量适配。物理参数、输入表面、远场比例和层数不随适配改变。

当前支持的自动恢复范围仅为 OpenFOAM 单项高偏斜失败：尝试初始壁面间距比例、其两倍、其一半，最多三次；每次创建独立版本，旧网格与日志保留。其他质量问题、文件缺失、权限问题和手工上传的 Pointwise 工程不会触发这种自动改写。不会降低 checkMesh 验收标准，也不通过改变黏度等物性伪造稳定性。

此策略用于流程诊断。壁面间距变化会影响边界层分辨率，不能用于要求固定首层高度的工程算例。界面允许关闭自动质量适配；工程网格应先确定 y+ 与首层高度、层数、增长率、远场和局部加密要求，再在约束内优化，尚未实现完整工程约束优化器。

实测：任务 14c3412d1a01414a9c3a4ef42f342a3f 的原 v1 未通过。启动通用重试后，v2 按初始比例 0.001 重现 18 个高偏斜面失败；系统根据真实日志自动创建 v3，比例 0.002 的体网格完成导出、毫米转米，普通 checkMesh 返回 Mesh OK。没有按模型名称指定 0.002，没有导入预先保存的网格替代本次生成。

模型原始几何仍需通过检查。当前也没有验证任意飞机外形、复杂半模型、多部件边界、可压缩湍流工况、长期稳定性或气动精度。已通过的网格检查不等于上述能力通过。

API：首次生成 volume-mesh 接受 auto_quality=true/false；对高偏斜失败任务，retry-volume-auto 启动新适配轮次。volume_settings.json 保存每次参数、父版本和调整原因；当前及历史产物均可下载。前端移除了某个演示文件专用的参数提示。
