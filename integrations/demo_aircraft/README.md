# Small aircraft workflow test fixture

`demo_aircraft_v3.stl` is a deliberately simplified, smooth aircraft-shaped **surface mesh** generated by `generate.py`. It includes a fuselage, symmetric main wings, horizontal tail lobes and a vertical tail lobe. Units are millimeters; bounds are approximately x ±12, y ±11.34, z -2.2 to 4.31 mm. It is not CRM CAD or an aerodynamic validation model.

`demo_aircraft_v3.ansa` is an ANSA mesh project imported from the STL. It contains 20,448 shell facets and no CAD FACE entities. Use the STL for browser preview or meshing, and the ANSA file for ANSA inspection.

`demo_aircraft_test.igs` is a separate, simplified CAD approximation of the same illustrative shape. `write_iges.py` generates six piecewise bilinear IGES type-128 patches in millimeters. It is not an exact conversion of every STL triangle and is not CRM geometry. ANSA 20.1.6 re-imported it as six CAD FACE entities. After `Topo(cons="all")`, it had 12 shared CONS, zero free CONS and zero detected CAD intersections (`iges_topology.json`). ANSA produced a 1,412-triangle surface mesh from it; that mesh had one connected component, zero boundary/nonmanifold edges and zero degenerate facets (`../../data/demo_aircraft_iges_check/surface_quality.json`). This validates CAD import and a closed surface mesh, not a volume mesh or a flow solve from this IGES.

Checks performed:

- Surface: one connected component, zero boundary edges, zero nonmanifold edges, zero degenerate facets (`surface_quality_v3.json`).
- Pointwise: zero surface intersections; 250,664 volume cells; zero negative/zero Jacobian cells (`../../data/demo_aircraft_v3/pointwise.log`). The minimum Jacobian is 0.001905 and maximum equiangle skew is 0.992667, so this is a pipeline test mesh, not an accepted production quality mesh.
- Pointwise project and CGNS volume mesh are in `../../data/demo_aircraft_v3/`.

OpenFOAM `checkMesh`, boundary-condition verification and a flow solve have **not** been completed for this test aircraft. Do not present its mesh as solver validated.
