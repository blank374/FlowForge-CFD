# CRM WB 标准流程建设记录

本轮完成标准验收入口、参数方案与旧结果隔离，尚未完成 CRM 工程求解与实验验证。不得把方案生成或通用两步测试标记为标准验收通过。

## 已实现

- 通用任务详情提供 standard_assessment，界面逐项展示标准几何、网格、物理、收敛和实验验证的证据缺口。
- POST /api/workflows/crm-plan 校验参考弦长、面积、半展长和攻角，计算理想气体静态来流、指定 Re 对应黏度及标准网格计划；只生成方案，不执行求解。
- 增长率暂按严格 <1.2、远场按 >100 半展长处理。原文后缘数量与长度换算问题保留为待澄清项。
- force_coefficients.csv 接受 iteration,CL,CD,Cm 列，检查有限值、严格递增迭代号与最近 25/50 步 CL 均值差。它仅支持验收分析，尚未连接求解器实时输出与自动终止。
- 求解重试与物理配置的新版本不复制旧报告、结果 JSON、图像、后处理记录、力系数和 case 压缩包。
- pytest 默认仅收集 tests，避免在普通 Python 中导入 ANSA 专用诊断脚本。

## 验证

15 项 pytest 回归通过；前端 TypeScript 和 Vite 生产构建通过；git diff --check 通过。未重新执行标准 CRM 算例，也未重启现有服务。前端构建仍有大资源包警告。

## 待完成的工程链

1. 确定设计外形基准并修复 CRM 接缝；保持输入与修复版本可追溯。
2. 实施 wing/body 局部网格和对称面方案，对首层高度、增长率、远场、体积比进行实测验收。
3. 以本机 OpenFOAM 13 官方 fluid/aerofoilNACA0012Steady 教程为兼容性依据，实现可压缩 kOmegaSST 完整字典与边界；审核参考量、入口湍流、壁面处理和温压一致性。
4. 连接真实 CL/CD/Cm 输出、滑动平均收敛监控、暂停与已有流场续算。现有 retry-solver 仍从时间零重跑。
5. 实现剖面 Cp、同工况 DPW 数据对比和网格敏感性分析，再允许工程验收。

当前 standard_assessment 故意保持 engineering_ready=false，几何/网格/实验项尚无可认可的自动验收数据格式。不能通过上传自写合格 JSON 放行。
