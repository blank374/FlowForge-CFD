# 新建无尾后掠翼身测试模型

这是新生成的完整闭合外形，参考原始 DPW4 WB 的无尾翼身布局，包含机身和左右后掠翼，不含平尾或垂尾。它是全模型，不是原 CRM 半模型的修复版，也不具有原 CRM 的真实翼型、外形或实验对应关系。

## 直接使用

1. 解压后上传 crm_like_wb_clean.igs。
2. 在工作台选择通用外流场，执行几何检查并审核。
3. 表面网格目标尺寸填写 12 mm，运行表面网格。生成 Pointwise 体网格前，将“初始壁面间距 / 模型最大尺寸”填写 0.002；旧默认 0.001 曾产生 18 个高偏斜面，未通过 OpenFOAM 检查。
4. 不要选择 L1 球体模板，也不要沿用小飞机的 0.25 mm 尺寸。

单位毫米，长 1500 mm，展长约 1163 mm，厚度约 150 mm。几何以 384 个双线性 B 样条面片连接，是可导入的 CAD 而非仅 STL。机翼尖和机鼻经过简化，并非工业级光顺曲面。

## 已实际验证

- ANSA 20.1.6 导入 384 个 CAD FACE，Topo 后 768 个 CONS；自由边、非流形边、游离边均为 0，指定几何检查未报告残留错误。
- ANSA 12 mm 表面网格为 5424 个 shell，导出的 STL 为 10130 个三角形，独立闭合检查通过；导出包围盒保留完整翼展。
- ANSA 面网格相交检查未报告相交区域；Pointwise 已执行脚本中的表面相交门槛并完成体网格。
- Pointwise 2024.1 生成 326412 个体单元，负/零 Jacobian 均为 0，最小 Jacobian 0.015301，最大等角偏斜指标约 0.967748。这些指标不等于生产网格质量认证。
- OpenFOAM 普通网格检查已在调整后的 0.002 比例网格上通过；新模型的求解、长期稳定性与结果精度尚未验证，不能承诺任意工况都能计算成功。

后续实际复检补充：初始比例 0.001 的网格 OpenFOAM 最大偏斜度 4.8599，18 个高偏斜面，Failed 1 mesh checks；在独立副本中保持输入表面、3 层和远场比例不变，仅把初始壁面间距比例改为 0.002，最大偏斜度降到 3.3454，普通 checkMesh 返回 Mesh OK。修改后仍有 32 个大于 70° 的非正交面，不能据此认证工程网格。当前通过版原生网格位于项目 data/wb_volume_trial_0.002/pointwise，而本包 volume_validation 为最初比例 0.001 的历史网格，不要把它当作 OpenFOAM 已通过版本。

更新后的模型包另含 volume_checked，保存通过版原生工程与检查日志。工作台任务 fa32a5cd2eba4497bfd282ceed97da0c 的 v2 已完成重新导出、毫米转米和普通 checkMesh，最终 Mesh OK，当前等待求解配置，未自动开始求解。

## 文件

- crm_like_wb_clean.igs：建议上传的输入几何。
- crm_like_wb_clean.ansa：本次 ANSA 几何检查保存的原生工程。
- surface_validation：真实表面网格工程、STL、质量 JSON 与日志。
- volume_validation：Pointwise 原生工程、CGNS 与日志。
- preview.png：俯视及立体预览；preview.stl 是用于预览的几何采样网格，实际 CFD 表面网格使用 surface_validation/surface.stl。
- design.json、geometry_check.json：设计范围及实际检查记录。

原始 CRM 文件未修改。该模型用于测试导入、网格、人工协作和求解设置，不用于 DPW 实验对比。
